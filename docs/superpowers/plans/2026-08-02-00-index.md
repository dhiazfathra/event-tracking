## Deliberately not built

These are spec §7 open questions or explicitly-deferred items. No task implements
them; do not add them opportunistically.

- Retention tiering beyond the flat 13-month TTL (§7.1)
- Per-user GDPR deletion, rollup rebuild fencing, deletion epoch (§3.7, §7.2)
- Schema registry enforcement / strict mode (§7.3)
- A tuned `props` cardinality limit — the flat >50 rejection ships as-is (§7.5)
- Server-pushed query cache invalidation (§7.6)
- The `by_user` projection (§3.5)
- Kafka, sharding, replicas (§3.8)
- Rollup routing in the query service is **read-only and labelled**; per-user
  deletion is not supported, so the rebuild-fence problem in §3.7 cannot arise yet.
