# Flutter SDK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `clients/flutter_sdk` — a drift/SQLite outbox that is the ingestion queue, a sync engine implementing the full status-code contract, a read-through query cache, and an example app.

**Architecture:** `Tracker.track()` commits one row to SQLite and returns. It never blocks meaningfully and never throws into host app code. A flush trigger claims up to 500 `pending` rows in a transaction, marks them `inflight`, and POSTs them; the response drives delete/dead/retry per event. `inflight` is persisted, not in-memory, so a process kill mid-request loses nothing — resend is safe because `event_id` is stable and the server dedups on read. The query cache is read-through and strictly derived: the server always wins, and locally-captured-but-unsent events are never folded into cached aggregates.

**Tech Stack:** Dart 3.5+/Flutter 3.24+, `drift` + `sqlite3_flutter_libs`, `http`, `connectivity_plus`, `workmanager`, `uuid` (v7), `build_runner`, `mocktail`.

## Global Constraints

Copied verbatim from the spec. Every task's requirements implicitly include this section.

- `track()` never blocks the caller meaningfully and **never throws into host app code**.
- **No in-memory buffer.** Every event is committed to disk the moment it is captured.
- `PRAGMA journal_mode=WAL; PRAGMA synchronous=NORMAL;` — durability boundary is **application crash, not power loss**. Captures in the seconds before a hard reboot can be lost. This is deliberate and counted, not glossed as "durable".
- Outbox capped at **10,000 rows across every state**. Overflow evicts the oldest `pending` first; if all 10,000 are `inflight`, the **new capture is dropped instead**. Both increment `dropped_events`.
- A capture-time write failure is caught, counted in `write_failures`, and swallowed.
- `dropped_events` and `write_failures` ship as an `sdk_dropped_events` event on the next successful batch, and are exposed on a diagnostics API.
- Batch claim: ≤500 rows, `ORDER BY seq`, in a `BEGIN IMMEDIATE` transaction.
- `inflight` rows older than **5 minutes** reset to `pending` — checked on SDK init **and at the start of every flush cycle**, not init alone.
- Backoff: exponential from **2s, doubling, capped at 5 minutes, ±25% jitter**. Jitter is not cosmetic — without it every client that failed during an outage retries in lockstep on recovery.
- After **20 attempts (~1.5h)** an event is marked `dead` and retained **7 days** for diagnostics.
- Status contract: `200` delete accepted / mark rejected dead; `400` drop batch, no retry; `401` re-exchange and retry once, then stop syncing and surface to the host app; `413` halve batch — **if already a single event, mark it `dead`**; `429` retry after `Retry-After`; `5xx`/timeout retry with backoff.
- Flush triggers: 30s timer while foregrounded, pending ≥ 50, background transition, connectivity regained, explicit `flush()`.
- **Connectivity events are a hint, never proof** — captive portals report connected. Only an HTTP success counts as success.
- **iOS background sync is opportunistic and the SDK does not promise it.**
- Events have no conflicts. No CRDTs, no vector clocks, no last-write-wins.
- Query cache: server always wins. Local unsent events are **never** folded into cached aggregates. `optimistic: true` surfaces them as a separately labelled value.
- The SDK and the services share exactly one thing: `gen/`. Golden fixtures in `testdata/golden/` are parsed by the Dart tests too.

```dart
import 'package:drift/drift.dart';
import 'package:drift/native.dart';

part 'database.g.dart';

/// Lifecycle of an outbox row.
///
/// `inflight` is persisted rather than held in memory: if the process dies
/// mid-request an in-memory marker loses the events entirely.
enum OutboxState { pending, inflight, dead }

/// The outbox IS the ingestion queue. Every phone holds its own unsent events
/// on disk and retries with backoff, which is what lets the backend run
/// without a separate durable buffer tier.
@DataClassName('OutboxRow')
class Outbox extends Table {
  /// UUID v7. Stable across every retry — this is the idempotency key the
  /// server dedups on, and what makes crash recovery a two-line fix.
  TextColumn get eventId => text()();

  /// Per-device monotonic. Claim order, and server-side gap detection.
  IntColumn get seq => integer()();

  /// Serialized envelope. Stored rather than rebuilt so a schema change in the
  /// app cannot alter an already-captured event.
  BlobColumn get payload => blob()();

  IntColumn get createdAt => integer()();
  IntColumn get attempts => integer().withDefault(const Constant(0))();
  IntColumn get nextAttemptAt => integer().withDefault(const Constant(0))();
  TextColumn get state => textEnum<OutboxState>()();

  @override
  Set<Column> get primaryKey => {eventId};
}

@DataClassName('QueryCacheRow')
class QueryCacheEntries extends Table {
  TextColumn get cacheKey => text()();
  BlobColumn get body => blob()();
  TextColumn get etag => text().nullable()();

  /// Server-side computation time. What the UI shows as "as of".
  IntColumn get computedAt => integer()();

  /// When this device received it. What TTL expiry is measured from.
  IntColumn get fetchedAt => integer()();

  IntColumn get ttlMs => integer()();

  @override
  Set<Column> get primaryKey => {cacheKey};
}

/// 'seq', 'dropped_events', 'write_failures'.
@DataClassName('CounterRow')
class Counters extends Table {
  TextColumn get name => text()();
  IntColumn get value => integer()();

  @override
  Set<Column> get primaryKey => {name};
}

@DriftDatabase(tables: [Outbox, QueryCacheEntries, Counters])
class TrackingDatabase extends _$TrackingDatabase {
  TrackingDatabase(super.e);

  /// In-memory database for tests. Not for production use: an in-memory
  /// outbox defeats the entire point of the design.
  factory TrackingDatabase.memory() => TrackingDatabase(NativeDatabase.memory());

  @override
  int get schemaVersion => 1;

  @override
  MigrationStrategy get migration => MigrationStrategy(
        onCreate: (m) async {
          await m.createAll();
          // Covers the flush claim: WHERE state=? AND next_attempt_at<=?
          // ORDER BY seq LIMIT 500.
          await customStatement(
            'CREATE INDEX outbox_ready ON outbox(state, next_attempt_at, seq)',
          );
        },
        beforeOpen: (details) async {
          // WAL makes the per-capture write cheap enough that no in-memory
          // buffer is needed. synchronous=NORMAL keeps the database consistent
          // across a power cut but can roll back the most recent commits:
          // process crash loses nothing, a kernel panic can lose the last few
          // seconds of captures. That window is accepted deliberately —
          // synchronous=FULL would cost an fsync per captured event inside
          // someone else's app.
          await customStatement('PRAGMA journal_mode = WAL');
          await customStatement('PRAGMA synchronous = NORMAL');
          await customStatement('PRAGMA foreign_keys = ON');
        },
      );
}
```

`clients/flutter_sdk/lib/src/outbox/outbox.dart`:

```dart
import 'dart:typed_data';

import 'package:drift/drift.dart';

import '../db/database.dart';

/// Hard cap across every state. An unbounded outbox on a long-offline device
/// fills the host app's storage and gets the app uninstalled.
const kMaxOutboxRows = 10000;

/// An inflight row older than this is assumed abandoned — a killed process, a
/// timed-out request, or a dead flush worker.
const kInflightTimeoutMs = 5 * 60 * 1000;

/// Dead events are kept for diagnostics, then dropped.
const kDeadRetentionMs = 7 * 24 * 60 * 60 * 1000;

const _kDroppedEvents = 'dropped_events';

class Outbox {
  Outbox(this._db);

  final TrackingDatabase _db;

  /// Appends a captured event.
  ///
  /// Returns false if the event was dropped because the outbox is full of
  /// inflight rows. Either way the caller does not need to handle an error:
  /// losing the oldest telemetry is the correct failure — but it must be
  /// *visible*, which is what the counter is for.
  Future<bool> add({
    required String eventId,
    required int seq,
    required Uint8List payload,
    required int nowMs,
  }) {
    return _db.transaction(() async {
      final total = await _countAll();
      if (total >= kMaxOutboxRows) {
        final evicted = await _evictOldestPending();
        await _bumpCounter(_kDroppedEvents, 1);
        if (!evicted) {
          // Every row is inflight — a flush is stuck or in progress. Dropping
          // the incoming capture is better than exceeding the cap.
          return false;
        }
      }

      await _db.into(_db.outbox).insert(
            OutboxCompanion.insert(
              eventId: eventId,
              seq: seq,
              payload: payload,
              createdAt: nowMs,
              state: OutboxState.pending,
            ),
            // A replayed capture of the same event_id is a no-op, not a
            // duplicate row and not an exception into host app code.
            mode: InsertMode.insertOrIgnore,
          );
      return true;
    });
  }

  /// Claims up to [limit] ready rows and marks them inflight atomically.
  ///
  /// The transaction is what makes crash-safety work: without it a process
  /// death between the SELECT and the UPDATE either loses the rows or sends
  /// them twice from two flush cycles.
  Future<List<OutboxRow>> claim({required int nowMs, int limit = 500}) {
    return _db.transaction(() async {
      final rows = await (_db.select(_db.outbox)
            ..where((t) =>
                t.state.equalsValue(OutboxState.pending) &
                t.nextAttemptAt.isSmallerOrEqualValue(nowMs))
            ..orderBy([(t) => OrderingTerm.asc(t.seq)])
            ..limit(limit))
          .get();

      if (rows.isEmpty) return rows;

      final ids = rows.map((r) => r.eventId).toList();
      await (_db.update(_db.outbox)..where((t) => t.eventId.isIn(ids))).write(
        OutboxCompanion(
          state: const Value(OutboxState.inflight),
          // Reused as the inflight-since marker by resetStaleInflight.
          nextAttemptAt: Value(nowMs),
        ),
      );
      return rows;
    });
  }

  Future<void> deleteAccepted(List<String> eventIds) async {
    if (eventIds.isEmpty) return;
    await (_db.delete(_db.outbox)..where((t) => t.eventId.isIn(eventIds))).go();
  }

  Future<void> markDead(List<String> eventIds) async {
    if (eventIds.isEmpty) return;
    await (_db.update(_db.outbox)..where((t) => t.eventId.isIn(eventIds)))
        .write(const OutboxCompanion(state: Value(OutboxState.dead)));
  }

  Future<void> requeue(List<String> eventIds, {required int nextAttemptAt}) async {
    if (eventIds.isEmpty) return;
    await _db.customStatement(
      'UPDATE outbox SET state = ?, attempts = attempts + 1, next_attempt_at = ? '
      'WHERE event_id IN (${List.filled(eventIds.length, '?').join(',')})',
      [OutboxState.pending.name, nextAttemptAt, ...eventIds],
    );
  }

  /// Resets abandoned inflight rows.
  ///
  /// Called on SDK init *and* at the start of every flush cycle — not init
  /// alone, so a timed-out request or a dead flush worker does not leave rows
  /// stuck until the app happens to restart. Resending is safe because
  /// event_id is stable and the server dedups on read.
  Future<int> resetStaleInflight({required int nowMs}) async {
    final cutoff = nowMs - kInflightTimeoutMs;
    return (_db.update(_db.outbox)
          ..where((t) =>
              t.state.equalsValue(OutboxState.inflight) &
              t.nextAttemptAt.isSmallerOrEqualValue(cutoff)))
        .write(const OutboxCompanion(state: Value(OutboxState.pending)));
  }

  Future<void> purgeExpiredDead({required int nowMs}) async {
    final cutoff = nowMs - kDeadRetentionMs;
    await (_db.delete(_db.outbox)
          ..where((t) =>
              t.state.equalsValue(OutboxState.dead) &
              t.createdAt.isSmallerOrEqualValue(cutoff)))
        .go();
  }

  Future<int> pendingCount() async {
    final count = _db.outbox.eventId.count();
    final row = await (_db.selectOnly(_db.outbox)
          ..addColumns([count])
          ..where(_db.outbox.state.equalsValue(OutboxState.pending)))
        .getSingle();
    return row.read(count) ?? 0;
  }

  Future<int> counter(String name) async {
    final row = await (_db.select(_db.counters)..where((t) => t.name.equals(name)))
        .getSingleOrNull();
    return row?.value ?? 0;
  }

  Future<void> bumpCounter(String name, int by) => _bumpCounter(name, by);

  Future<void> resetCounter(String name) async {
    await (_db.delete(_db.counters)..where((t) => t.name.equals(name))).go();
  }

  Future<int> nextSeq() async {
    return _db.transaction(() async {
      final current = await counter('seq');
      await _bumpCounter('seq', 1);
      return current + 1;
    });
  }

  Future<int> _countAll() async {
    final count = _db.outbox.eventId.count();
    final row = await (_db.selectOnly(_db.outbox)..addColumns([count])).getSingle();
    return row.read(count) ?? 0;
  }

  /// Returns false when there is no pending row to evict.
  Future<bool> _evictOldestPending() async {
    final oldest = await (_db.select(_db.outbox)
          ..where((t) => t.state.equalsValue(OutboxState.pending))
          ..orderBy([(t) => OrderingTerm.asc(t.seq)])
          ..limit(1))
        .getSingleOrNull();
    if (oldest == null) return false;

    await (_db.delete(_db.outbox)..where((t) => t.eventId.equals(oldest.eventId))).go();
    return true;
  }

  Future<void> _bumpCounter(String name, int by) async {
    await _db.customStatement(
      'INSERT INTO counters(name, value) VALUES (?, ?) '
      'ON CONFLICT(name) DO UPDATE SET value = value + ?',
      [name, by, by],
    );
  }
}
```

```dart
import 'dart:math';

const kBackoffBase = Duration(seconds: 2);
const kBackoffCap = Duration(minutes: 5);

/// After 20 attempts (~1.5h of retries) the event is marked dead. This is
/// intentional, counted, bounded loss — not an unconditional "never lost".
const kMaxAttempts = 20;

const _jitterFraction = 0.25;

final _defaultRandom = Random();

/// Exponential backoff from 2s, doubling, capped at 5 minutes, with ±25%
/// jitter.
Duration backoffFor(int attempts, {Random? random}) {
  final n = attempts < 1 ? 1 : attempts;

  // Cap the exponent before shifting: 1 << 60 is a valid int and would
  // overflow the duration arithmetic on the way to being clamped.
  final exponent = n - 1 > 20 ? 20 : n - 1;
  var ms = kBackoffBase.inMilliseconds * (1 << exponent);
  if (ms > kBackoffCap.inMilliseconds) {
    return kBackoffCap;
  }

  final r = (random ?? _defaultRandom).nextDouble(); // [0, 1)
  final factor = 1 + (_jitterFraction * (2 * r - 1)); // [0.75, 1.25)
  ms = (ms * factor).round();

  return Duration(milliseconds: ms);
}
```

```dart
import 'dart:convert';

import 'package:http/http.dart' as http;

/// Holds the short-lived ingest token and exchanges the public client ID for a
/// fresh one when needed.
///
/// The client ID embedded in the app is public and authorizes nothing. The
/// token is the actual credential, and it expires — which is what makes an
/// extracted client ID boring rather than a breach.
abstract class TokenStore {
  Future<String?> token();
  void invalidate();
}

class HttpTokenStore implements TokenStore {
  HttpTokenStore({
    required this.baseUrl,
    required this.clientId,
    required this.platform,
    required http.Client httpClient,
    this.attestation,
    DateTime Function()? now,
  })  : _http = httpClient,
        _now = now ?? DateTime.now;

  final Uri baseUrl;
  final String clientId;
  final String platform;
  final String? attestation;
  final http.Client _http;
  final DateTime Function() _now;

  String? _token;
  DateTime? _expiresAt;

  @override
  Future<String?> token() async {
    final cached = _token;
    final expiry = _expiresAt;
    // Refresh a minute early so a request never races the expiry.
    if (cached != null && expiry != null && _now().isBefore(expiry.subtract(const Duration(minutes: 1)))) {
      return cached;
    }

    try {
      final res = await _http.post(
        baseUrl.resolve('/v1/auth/token'),
        headers: const {'content-type': 'application/json'},
        body: jsonEncode({
          'clientId': clientId,
          'platform': platform,
          if (attestation != null) 'attestation': attestation,
        }),
      );
      if (res.statusCode != 200) return null;

      final body = jsonDecode(res.body) as Map<String, dynamic>;
      _token = body['accessToken'] as String?;
      final expiresIn = int.tryParse('${body['expiresIn']}') ?? 1800;
      _expiresAt = _now().add(Duration(seconds: expiresIn));
      return _token;
    } catch (_) {
      // A failed exchange is not an error the host app should see. The sync
      // engine treats a null token as "cannot sync right now" and retries.
      return null;
    }
  }

  @override
  void invalidate() {
    _token = null;
    _expiresAt = null;
  }
}
```

```dart
import 'dart:convert';
import 'dart:io';

import 'package:http/http.dart' as http;

import 'token_store.dart';

export 'token_store.dart';

class RejectInfo {
  const RejectInfo(this.eventId, this.code, this.message);
  final String eventId;
  final String code;
  final String message;
}

/// The outcomes the status contract defines. Modelled as a sealed class so the
/// sync engine cannot silently forget to handle one.
sealed class BatchOutcome {
  const BatchOutcome();
}

class Accepted extends BatchOutcome {
  const Accepted(this.accepted, this.rejected);
  final List<String> accepted;
  final List<RejectInfo> rejected;
}

/// 400 — the envelope is malformed. Drop the batch, do not retry.
class Malformed extends BatchOutcome {
  const Malformed();
}

/// 401 — re-exchange for a fresh token and retry once.
class Unauthorized extends BatchOutcome {
  const Unauthorized();
}

/// 413 — halve the batch. If it is already one event, that event is
/// unshippable and must be marked dead or it loops on 413 forever.
class TooLarge extends BatchOutcome {
  const TooLarge();
}

class RateLimited extends BatchOutcome {
  const RateLimited(this.retryAfter);
  final Duration retryAfter;
}

class ServerError extends BatchOutcome {
  const ServerError();
}

/// A timeout or connection failure. Retrying is safe because event_id is
/// stable — the server dedups a re-delivery on read.
class NetworkError extends BatchOutcome {
  const NetworkError();
}

class Transport {
  Transport({
    required this.baseUrl,
    required http.Client httpClient,
    required TokenStore tokenStore,
    required this.clientId,
    this.timeout = const Duration(seconds: 30),
  })  : _http = httpClient,
        _tokens = tokenStore;

  final Uri baseUrl;
  final String clientId;
  final Duration timeout;
  final http.Client _http;
  final TokenStore _tokens;

  Future<BatchOutcome> postBatch(
    List<Map<String, dynamic>> events, {
    required int sentAtMs,
  }) async {
    final token = await _tokens.token();
    if (token == null) return const Unauthorized();

    // sentAt is int64 in the proto, so proto-JSON requires a string. Emitting
    // a number here parses fine in Dart and is rejected by the server.
    final payload = jsonEncode({
      'sentAt': '$sentAtMs',
      'events': events,
    });

    try {
      final req = http.Request('POST', baseUrl.resolve('/v1/batch'))
        ..headers.addAll({
          'authorization': 'Bearer $token',
          'content-type': 'application/json',
          'content-encoding': 'gzip',
        })
        ..bodyBytes = gzip.encode(utf8.encode(payload));

      final streamed = await _http.send(req).timeout(timeout);
      final res = await http.Response.fromStream(streamed);
      return _mapResponse(res);
    } catch (_) {
      return const NetworkError();
    }
  }

  BatchOutcome _mapResponse(http.Response res) {
    switch (res.statusCode) {
      case 200:
        return _parseAccepted(res.body);
      case 400:
        return const Malformed();
      case 401:
        _tokens.invalidate();
        return const Unauthorized();
      case 413:
        return const TooLarge();
      case 429:
        return RateLimited(_retryAfter(res));
      default:
        return const ServerError();
    }
  }

  Accepted _parseAccepted(String body) {
    try {
      final map = jsonDecode(body) as Map<String, dynamic>;
      final accepted = ((map['accepted'] as List<dynamic>?) ?? const [])
          .map((e) => e as String)
          .toList();
      final rejected = ((map['rejected'] as List<dynamic>?) ?? const [])
          .map((e) => e as Map<String, dynamic>)
          .map((e) => RejectInfo(
                e['eventId'] as String? ?? '',
                e['code'] as String? ?? 'UNKNOWN',
                e['message'] as String? ?? '',
              ))
          .toList();
      return Accepted(accepted, rejected);
    } catch (_) {
      // A 200 we cannot parse must not be treated as success: the caller would
      // delete rows that may never have been stored.
      return const Accepted([], []);
    }
  }

  Duration _retryAfter(http.Response res) {
    final header = res.headers['retry-after'];
    final seconds = header == null ? null : int.tryParse(header.trim());
    return Duration(seconds: seconds ?? 60);
  }
}
```

```dart
import 'dart:convert';
import 'dart:typed_data';

import '../db/database.dart';
import '../outbox/outbox.dart';
import '../transport/transport.dart';
import 'backoff.dart';

export 'backoff.dart';

typedef NowMs = int Function();

/// Drives the outbox against the ingest API.
///
/// Every branch here is a line in the published status-code contract. The SDK
/// ships inside third-party apps and cannot be force-upgraded, so getting one
/// of these wrong is not a bug you can hotfix.
class SyncEngine {
  SyncEngine({
    required Outbox outbox,
    required Transport transport,
    NowMs? nowMs,
    void Function(Object error)? onFatal,
  })  : _outbox = outbox,
        _transport = transport,
        _now = nowMs ?? (() => DateTime.now().millisecondsSinceEpoch),
        _onFatal = onFatal;

  final Outbox _outbox;
  final Transport _transport;
  final NowMs _now;
  final void Function(Object error)? _onFatal;

  /// Shrinks on 413 and stays shrunk: the server's limit does not change back
  /// mid-session, and re-growing would just re-discover the same 413.
  int batchSize = 500;

  /// Set when the token exchange itself fails. Syncing stops rather than
  /// spinning; the host app is told via [onFatal].
  bool halted = false;

  Future<void> init() async {
    await _outbox.resetStaleInflight(nowMs: _now());
    await _outbox.purgeExpiredDead(nowMs: _now());
  }

  Future<void> flushOnce() async {
    if (halted) return;

    // Not init alone: a timed-out request or a dead flush worker would
    // otherwise leave rows stuck until the app happens to restart.
    await _outbox.resetStaleInflight(nowMs: _now());

    final claimed = await _outbox.claim(nowMs: _now(), limit: batchSize);
    if (claimed.isEmpty) {
      await _reportCounters();
      return;
    }

    final outcome = await _transport.postBatch(
      claimed.map(_decode).toList(),
      sentAtMs: _now(),
    );

    await _apply(outcome, claimed, retriedAfterAuth: false);
  }

  Future<void> _apply(
    BatchOutcome outcome,
    List<OutboxRow> claimed, {
    required bool retriedAfterAuth,
  }) async {
    final ids = claimed.map((r) => r.eventId).toList();

    switch (outcome) {
      case Accepted(:final accepted, :final rejected):
        await _outbox.deleteAccepted(accepted);
        await _outbox.markDead(rejected.map((r) => r.eventId).toList());

        // Anything claimed but neither accepted nor rejected — a truncated
        // response, a server that dropped an id — goes back to pending. Safe,
        // because event_id is stable and the server dedups on read.
        final handled = {...accepted, ...rejected.map((r) => r.eventId)};
        final unhandled = ids.where((id) => !handled.contains(id)).toList();
        await _outbox.requeue(unhandled, nextAttemptAt: _now());

        await _reportCounters();

      case Malformed():
        // A malformed envelope will never succeed. Retrying it wedges the
        // outbox behind a batch that cannot drain.
        await _outbox.markDead(ids);

      case Unauthorized():
        if (retriedAfterAuth) {
          // The exchange itself is failing. Stop syncing and surface it — the
          // events stay on disk, so nothing is lost by waiting.
          halted = true;
          await _outbox.requeue(ids, nextAttemptAt: _now());
          _onFatal?.call(StateError('event_tracking: token exchange failed; sync halted'));
          return;
        }
        // The transport already invalidated the token, so this re-exchanges.
        final retry = await _transport.postBatch(
          claimed.map(_decode).toList(),
          sentAtMs: _now(),
        );
        await _apply(retry, claimed, retriedAfterAuth: true);

      case TooLarge():
        if (claimed.length == 1) {
          // Halving cannot shrink a single event below itself: it would loop
          // on 413 forever. Intentional, bounded, counted loss.
          await _outbox.markDead(ids);
          await _outbox.bumpCounter('dropped_events', 1);
          return;
        }
        batchSize = (batchSize ~/ 2).clamp(1, 500);
        await _outbox.requeue(ids, nextAttemptAt: _now());

      case RateLimited(:final retryAfter):
        // Honour the server's number rather than the local curve — it knows
        // when the budget resets and the local backoff does not.
        await _outbox.requeue(ids, nextAttemptAt: _now() + retryAfter.inMilliseconds);

      case ServerError():
      case NetworkError():
        await _retryOrBury(claimed);
    }
  }

  Future<void> _retryOrBury(List<OutboxRow> claimed) async {
    final exhausted = <String>[];
    final retryable = <String>[];

    for (final row in claimed) {
      if (row.attempts + 1 >= kMaxAttempts) {
        exhausted.add(row.eventId);
      } else {
        retryable.add(row.eventId);
      }
    }

    await _outbox.markDead(exhausted);
    if (retryable.isNotEmpty) {
      // All rows in a batch share an attempt count closely enough that one
      // backoff for the batch is correct and avoids N separate wakeups.
      final attempts = claimed.first.attempts + 1;
      await _outbox.requeue(
        retryable,
        nextAttemptAt: _now() + backoffFor(attempts).inMilliseconds,
      );
    }
  }

  /// Ships accumulated loss counters as a real event on the next flush.
  ///
  /// Appended to the outbox rather than injected into the batch just sent: if
  /// that batch failed, folding a diagnostic event into it could make the
  /// whole thing unshippable and lose the real events too.
  Future<void> _reportCounters() async {
    final dropped = await _outbox.counter('dropped_events');
    final writeFailures = await _outbox.counter('write_failures');
    if (dropped == 0 && writeFailures == 0) return;

    final seq = await _outbox.nextSeq();
    final payload = jsonEncode({
      'name': 'sdk_dropped_events',
      'props': {
        'dropped_events': {'numberValue': dropped},
        'write_failures': {'numberValue': writeFailures},
      },
    });

    await _outbox.add(
      eventId: 'diag-${_now()}-$seq',
      seq: seq,
      payload: Uint8List.fromList(utf8.encode(payload)),
      nowMs: _now(),
    );

    await _outbox.resetCounter('dropped_events');
    await _outbox.resetCounter('write_failures');
  }

  Map<String, dynamic> _decode(OutboxRow row) =>
      jsonDecode(utf8.decode(row.payload)) as Map<String, dynamic>;
}
```

```dart
/// A session is a contiguous stretch of app usage. It matters for one reason
/// on the server: the clock offset is persisted per
/// (tenant, device, session), so a session boundary is where the device's
/// clock is re-measured.
class Session {
  Session({Duration? timeout, DateTime Function()? now})
      : _timeout = timeout ?? const Duration(minutes: 30),
        _now = now ?? DateTime.now {
    _id = const Uuid().v7();
    _lastActivity = _now();
  }

  final Duration _timeout;
  final DateTime Function() _now;
  late String _id;
  late DateTime _lastActivity;

  String get id {
    if (_now().difference(_lastActivity) > _timeout) {
      renew();
    }
    _lastActivity = _now();
    return _id;
  }

  void renew() {
    _id = const Uuid().v7();
    _lastActivity = _now();
  }
}
```

```dart
/// The capture API.
///
/// Three non-negotiable properties:
///  1. track() never blocks the caller meaningfully — one WAL insert.
///  2. track() never throws into host app code.
///  3. There is no in-memory buffer. Every event hits disk immediately,
///     including the ones right before a crash, which are the ones that most
///     need capturing.
class Tracker {
  Tracker({
    required Outbox outbox,
    required this.deviceId,
    required this.sdkVersion,
    SyncEngine? sync,
    Session? session,
    String? appVersion,
    String? os,
    String? osVersion,
    String? locale,
    DateTime Function()? now,
  })  : _outbox = outbox,
        _sync = sync,
        _session = session ?? Session(),
        _appVersion = appVersion ?? '',
        _os = os ?? '',
        _osVersion = osVersion ?? '',
        _locale = locale ?? '',
        _now = now ?? DateTime.now;

  final Outbox _outbox;
  final SyncEngine? _sync;
  final Session _session;
  final String deviceId;
  final String sdkVersion;
  final String _appVersion;
  final String _os;
  final String _osVersion;
  final String _locale;
  final DateTime Function() _now;

  final _uuid = const Uuid();
  String? _userId;
  final String _anonymousId = const Uuid().v7();

  /// Associates subsequent events with a user. Past events are not rewritten —
  /// they are immutable facts, and the server stitches identity at query time
  /// via anonymous_id.
  void identify(String userId) {
    _userId = userId;
  }

  Future<void> track(String name, [Map<String, Object?> props = const {}]) async {
    try {
      final seq = await _outbox.nextSeq();
      final payload = jsonEncode({
        'eventId': _uuid.v7(),
        'name': name,
        // int64 on the wire means a JSON string under proto-JSON.
        'tsClient': '${_now().millisecondsSinceEpoch}',
        'seq': '$seq',
        'deviceId': deviceId,
        'sessionId': _session.id,
        'anonymousId': _anonymousId,
        if (_userId != null) 'userId': _userId,
        'props': _encodeProps(props),
        'context': {
          'sdkVersion': sdkVersion,
          'appVersion': _appVersion,
          'os': _os,
          'osVersion': _osVersion,
          'locale': _locale,
        },
      });

      final decoded = jsonDecode(payload) as Map<String, dynamic>;
      await _outbox.add(
        eventId: decoded['eventId'] as String,
        seq: seq,
        payload: Uint8List.fromList(utf8.encode(payload)),
        nowMs: _now().millisecondsSinceEpoch,
      );

      if (await _outbox.pendingCount() >= 50) {
        // Fire and forget: a flush must never make a capture slow.
        unawaited(_sync?.flushOnce() ?? Future<void>.value());
      }
    } catch (_) {
      // Disk full, mid-migration, closed database. The event is genuinely lost
      // — there is no durable fallback to fall back to — but the loss is
      // counted, not silent. Never rethrown: a telemetry SDK that can crash
      // the app it measures is a liability.
      try {
        await _outbox.bumpCounter('write_failures', 1);
      } catch (_) {
        // Even the counter failed. Nothing further to do.
      }
    }
  }

  Future<void> flush() async {
    try {
      await _sync?.flushOnce();
    } catch (_) {
      // Same contract as track(): never throw into host app code.
    }
  }

  Future<Diagnostics> diagnostics() async => Diagnostics(
        pending: await _outbox.pendingCount(),
        droppedEvents: await _outbox.counter('dropped_events'),
        writeFailures: await _outbox.counter('write_failures'),
      );

  /// Encodes props into the Value union. Unsupported types are dropped rather
  /// than thrown: a host app passing a DateTime should lose one property, not
  /// crash.
  Map<String, Object?> _encodeProps(Map<String, Object?> props) {
    final out = <String, Object?>{};
    props.forEach((k, v) {
      switch (v) {
        case final String s:
          out[k] = {'stringValue': s};
        case final bool b:
          out[k] = {'boolValue': b};
        case final num n:
          out[k] = {'numberValue': n.toDouble()};
        default:
          break; // dropped
      }
    });
    return out;
  }
}
```

```dart
///
/// The pending-count threshold lives in Tracker.track, because that is the
/// only place that knows a capture just happened.
class FlushTriggers with WidgetsBindingObserver {
  FlushTriggers({
    required Future<void> Function() flush,
    Duration period = const Duration(seconds: 30),
    Stream<List<ConnectivityResult>>? connectivity,
  })  : _flush = flush,
        _period = period,
        _connectivity = connectivity ?? Connectivity().onConnectivityChanged;

  final Future<void> Function() _flush;
  final Duration _period;
  final Stream<List<ConnectivityResult>> _connectivity;

  Timer? _timer;
  StreamSubscription<List<ConnectivityResult>>? _connSub;
  bool _online = true;

  void start() {
    _timer = Timer.periodic(_period, (_) => _safeFlush());

    _connSub = _connectivity.listen((results) {
      final online = results.any((r) => r != ConnectivityResult.none);
      // Only the offline→online edge. Connectivity events are a hint, never
      // proof — captive portals report connected, and only an HTTP success
      // counts as success. Flushing on every event would spam a captive
      // portal with retries.
      if (online && !_online) {
        _safeFlush();
      }
      _online = online;
    });

    WidgetsBinding.instance.addObserver(this);
  }

  @override
  void didChangeAppLifecycleState(AppLifecycleState state) {
    // Backgrounding is the most reliable flush point on iOS, where a
    // background task window is never guaranteed.
    if (state == AppLifecycleState.paused || state == AppLifecycleState.detached) {
      _safeFlush();
    }
  }

  Future<void> stop() async {
    _timer?.cancel();
    _timer = null;
    await _connSub?.cancel();
    _connSub = null;
    WidgetsBinding.instance.removeObserver(this);
  }

  void _safeFlush() {
    // A flush failure must never propagate out of a timer callback or a
    // stream listener — an unhandled async error there crashes the host app.
    _flush().catchError((Object _) {});
  }
}
```

```dart
import 'dart:convert';
import 'dart:typed_data';

import 'package:crypto/crypto.dart';
import 'package:drift/drift.dart';
import 'package:http/http.dart' as http;

import '../db/database.dart';

class CachedResult {
  const CachedResult({
    required this.body,
    required this.computedAt,
    required this.fromCache,
    this.pendingCount,
  });

  final Map<String, dynamic> body;

  /// Server-side computation time. Show this as "as of", not the fetch time.
  final int computedAt;

  final bool fromCache;

  /// Only populated when the caller asked for `optimistic: true`. Present as a
  /// separate label ("5,000 · 12 syncing"), never added to a total.
  final int? pendingCount;
}

/// Read-through cache over the query API.
///
/// Strictly derived and server-authoritative. The client never computes an
/// authoritative aggregate locally, and locally-captured-but-unsent events are
/// never merged into a cached total — a number that jumps to 5,012 and then
/// back to 5,000 when the server answers destroys trust faster than a number
/// being slightly stale.
class QueryCache {
  QueryCache({
    required TrackingDatabase db,
    required http.Client httpClient,
    required this.baseUrl,
    required this.readKey,
    required Future<int> Function() pendingCount,
    int Function()? nowMs,
  })  : _db = db,
        _http = httpClient,
        _pendingCount = pendingCount,
        _now = nowMs ?? (() => DateTime.now().millisecondsSinceEpoch);

  final TrackingDatabase _db;
  final http.Client _http;
  final Uri baseUrl;
  final String readKey;
  final Future<int> Function() _pendingCount;
  final int Function() _now;

  Future<CachedResult?> timeseries(
    Map<String, dynamic> spec, {
    Duration ttl = const Duration(minutes: 5),
    bool optimistic = false,
  }) async {
    final key = _cacheKey('timeseries', spec);
    final cached = await (_db.select(_db.queryCacheEntries)
          ..where((t) => t.cacheKey.equals(key)))
        .getSingleOrNull();

    final now = _now();
    if (cached != null && now - cached.fetchedAt < cached.ttlMs) {
      return _result(cached, fromCache: true, optimistic: optimistic);
    }

    try {
      final res = await _http.post(
        baseUrl.resolve('/v1/query/timeseries'),
        headers: {
          'authorization': 'Bearer $readKey',
          'content-type': 'application/json',
          if (cached?.etag != null) 'if-none-match': cached!.etag!,
        },
        body: jsonEncode(spec),
      );

      if (res.statusCode == 304 && cached != null) {
        // Refresh the TTL with no body transfer.
        await (_db.update(_db.queryCacheEntries)..where((t) => t.cacheKey.equals(key)))
            .write(QueryCacheEntriesCompanion(
          fetchedAt: Value(now),
          ttlMs: Value(ttl.inMilliseconds),
        ));
        return _result(cached, fromCache: true, optimistic: optimistic);
      }

      if (res.statusCode != 200) {
        return cached == null ? null : _result(cached, fromCache: true, optimistic: optimistic);
      }

      final body = jsonDecode(res.body) as Map<String, dynamic>;
      final computedAt = int.tryParse('${body['computedAt']}') ?? now;

      await _db.into(_db.queryCacheEntries).insertOnConflictUpdate(
            QueryCacheEntriesCompanion.insert(
              cacheKey: key,
              body: Uint8List.fromList(utf8.encode(res.body)),
              etag: Value(res.headers['etag']),
              computedAt: computedAt,
              fetchedAt: now,
              ttlMs: ttl.inMilliseconds,
            ),
          );

      return CachedResult(
        body: body,
        computedAt: computedAt,
        fromCache: false,
        pendingCount: optimistic ? await _pendingCount() : null,
      );
    } catch (_) {
      // Offline or a broken response. Serving stale is strictly better than
      // serving nothing — computedAt lets the UI label how old it is.
      return cached == null ? null : _result(cached, fromCache: true, optimistic: optimistic);
    }
  }

  Future<CachedResult> _result(
    QueryCacheRow row, {
    required bool fromCache,
    required bool optimistic,
  }) async =>
      CachedResult(
        body: jsonDecode(utf8.decode(row.body)) as Map<String, dynamic>,
        computedAt: row.computedAt,
        fromCache: fromCache,
        pendingCount: optimistic ? await _pendingCount() : null,
      );

  /// Hash of the endpoint plus the canonicalised spec. Keys are sorted so two
  /// semantically identical requests written in a different order share an
  /// entry rather than each holding their own copy.
  String _cacheKey(String endpoint, Map<String, dynamic> spec) {
    final sorted = Map.fromEntries(
      spec.entries.toList()..sort((a, b) => a.key.compareTo(b.key)),
    );
    return sha256.convert(utf8.encode('$endpoint:${jsonEncode(sorted)}')).toString();
  }
}
```

````markdown
# event_tracking

Offline-first event tracking SDK. The on-disk outbox **is** the ingestion
queue: the device holds its own unsent events and retries with backoff, which
is what lets the backend run without a separate durable buffer tier.

## Usage

```dart
final tracker = await EventTracking.init(
  clientId: 'pk_live_...',      // public, embedded, authorizes nothing
  baseUrl: Uri.parse('https://api.example.com'),
);

await tracker.track('checkout_completed', {'amount': 19.99, 'currency': 'IDR'});
tracker.identify('user-9');
await tracker.flush();
```

`track()` writes one row to SQLite and returns. It never blocks meaningfully
and **never throws into your app**.

## Delivery guarantee

**At-least-once, bounded by retry exhaustion and outbox capacity.** Not an
unconditional "never lost". Four loss boundaries exist, all counted and
reported, none silent:

1. **Outbox cap (10,000 rows).** The oldest `pending` row is evicted; if every
   row is `inflight`, the incoming capture is dropped instead.
2. **Retry exhaustion.** 20 attempts, roughly 1.5 hours, then `dead` (retained
   7 days for diagnostics).
3. **Capture-time write failure.** Disk full, mid-migration. Counted in
   `write_failures`.
4. **Power loss or kernel panic within seconds of a capture.** `synchronous=NORMAL`
   in WAL mode keeps the database consistent across a power cut but can roll
   back the most recent commits. **A process crash loses nothing.**
   `synchronous=FULL` would close this at the cost of an fsync per captured
   event — real battery and latency cost inside your app — so the narrow
   window is accepted deliberately.

Counters ship as an `sdk_dropped_events` event on the next successful batch and
are available via `tracker.diagnostics()`. A device that never syncs again
reports neither — that blind spot is inherent to client-side counters.

## iOS background sync

**Opportunistic. The SDK does not promise it.** iOS schedules background tasks
at its own discretion based on usage patterns, battery, and network; an app the
user opens rarely may not get a background window for days.

The reliable flush points on iOS are **foreground entry** and **background
transition**. If you need events sooner, call `flush()` yourself.

## Query cache

Read-through and strictly derived. The server always wins.

Locally-captured-but-unsent events are **not** folded into cached aggregates. A
count that shows 5,012 and then drops to 5,000 when the server answers destroys
trust in an analytics product faster than a number being slightly stale.

`optimistic: true` surfaces the pending count as a separately labelled value —
"5,000 · 12 syncing" — same information, no lying number.

## Why drift/SQLite

An outbox is exactly a queue table: transactional claim-and-delete, indexed
range scans on `(state, next_attempt_at)`, and real migrations. Hive has no
transactions, so an outbox on it loses or duplicates events on crash. Isar is
faster at raw object writes, but the outbox is not write-throughput-bound (a
busy app writes tens of events/sec, not thousands) and its maintenance history
is a bad property for a dependency shipping inside third-party apps.

The cost accepted: `build_runner` in the SDK's build.
````
